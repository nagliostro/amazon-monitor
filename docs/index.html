Monitor de Estoque

Para editar a lista, conecte um token do GitHub. Ele fica salvo só neste navegador.

Como criar o token

  1. Abra github.com/settings/personal-access-tokens/new.
  2. Em Repository access, escolha Only select repositories e marque amazon-monitor.
  3. Em Permissions, dê Read and write para Contents e para Actions.
  4. Gere o token e cole aqui.
